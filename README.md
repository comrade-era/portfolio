A dark, hacker-terminal themed personal portfolio website built with modern web technologies.

---

## ⚡ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer-motion.dev/)
- **Icons**: [Lucide React](https://lucide.dev/) + Custom SVGs
- **Theme**: Cyberpunk Terminal / Matrix Rain / Scanline HUD

---

## 🚀 Key Sections

- **Hero**: Terminal prompt `whoami`, dynamic typewriter title, status pill, CTAs, and matrix canvas background.
- **About**: Terminal bio window (`~/about_me.sh`), Quick Stats, Education, Certifications, Experience, and Leadership.
- **Technical Skills**: Security & Testing, Languages & Frameworks, Infrastructure, Red Team Tools, and Blue Team Tools.
- **Projects**: Filterable showcase including patent-pending AI threat intelligence pipeline (**NeuraSecure**), content integrity gate (**DefaceGuard**), and research on cybercrime catalysis.
- **Certifications**: Verified credentials (Google Cybersecurity, Palo Alto Networks, CCNA, Picus Threat Hunting).
- **Writings & Media**: Medium articles feed and Comrade Security YouTube educational content.
- **Achievements**: Hackathon wins, SIH qualifier, TryHackMe ranking, DSA problem-solving.
- **Contact**: Secure PGP communication note, social links, and terminal messaging interface.

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
git clone https://github.com/comrade-era/portfolio.git
cd portfolio
npm install
```

### Running Locally
```bash
npm run dev
```

### Building for Production
```bash
npm run build
npm run preview
```
